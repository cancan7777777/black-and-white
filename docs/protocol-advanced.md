# 进阶规则与通信约定

对应 #2、#4、#11–#14。四关计分及 188 分门槛按用户确认的新版规则实现。课程任务书来源和验收原文见[需求矩阵](requirements.md)。

## 对局与结算

- 玩家分归黑方。普通、计时和 AI 对弈按结算时的黑棋数计分，闯关将结算时的黑棋数乘以本关系数。自然终局按黑白棋数判胜负。合法落子后，若下一手一方无合法落子，则立即终局。
- 普通、闯关和 AI 对弈在自然终局累计本局分。计时模式在自然终局或剩余时间到零时，以先发生者结算。暂停与编辑冻结计时。暂停、编辑、终局均拒绝普通落子。
- 闯关共四关，系数依次为 **0.5、1、1.5、2**，按 0.5 分的精度累计。结算后累计**达到或超过 188 分**即显示 `WIN`。两连败或第四关结算后总分仍低于 188 分时显示 `OVER`。胜局或平局打断连败。若同时达到 `WIN` 和 `OVER` 条件，优先 `WIN`。
- 闯关由玩家执黑，STM32 执白。电脑优先选择能下的角，其余选能翻最多棋子的合法位置。同分时按棋盘行列顺序选择。电脑回合等待约 250 ms，暂停或编辑会冻结这段等待。
- AI 对弈由玩家执黑、Egaroucid 执白，实体 S15 和 LabVIEW 可开启。STM32 等白棋通过 `@AI` 提交，再用同一棋规校验和结算。
- 启动后默认进入普通第一局。闯关的正常关卡结算后，`START` 或 `RESTART` 进入下一关。对局中 `RESTART` 重开同一关。`WIN` 或 `OVER` 时立即退出闯关并保留闯关档案及显示，`START` 或 `RESTART` 开普通新局。主动结束对局后重新开始会清空本模式累计。重新设定模式会清零。
- 编辑模式允许修改格子颜色。至少一次有效改动后，对局标记为编辑局。编辑局可回放，结算后重打同一关，累计和排行跳过该局。退出编辑回到原运行或暂停状态。
- 排行按模式和来源分开，按得分降序、用时升序、结束时间升序。保存活动用时与结束时间，保留全部有效条目。每模式可保存至少 5 条，实际条目来自完成的对局。

## 串口帧

ASCII，逗号分隔，最后加 CRC-16/CCITT-FALSE 四位十六进制及 LF。缓冲上限 192 字节，坐标从 0 开始，序号 0 保留给下位机主动同步。变更命令使用最新修订号 `rev`，旧修订号返回 `STALE`。棋盘编码空、黑、白分别为 `0`、`1`、`2`。

| 主机请求 | 用途 |
|---|---|
| `@SYNC5,seq` | 读取当前模式及四关计分，启用 `@GAME5` 回复和主动上报 |
| `@SYNC4,seq` | 兼容旧版闯关自动退出和板载 AI 协商 |
| `@SYNC3,seq` | 读取四关计分状态，并启用 `@GAME3` 回复和主动上报 |
| `@SYNC2,seq` | 读取和 `@SYNC` 相同的棋盘字段，回复 `@GAME2` 表示支持电脑走白 |
| `@SYNC,seq` | 读取全部棋盘、进阶状态和剩余时间 |
| `@PLAY,seq,rev,row,col` | 确认普通落子 |
| `@AI,seq,rev,row,col` | 提交 Egaroucid 白棋，仅在 AI 对弈的白方回合有效 |
| `@CTL,seq,rev,op,value,seconds` | `START`、`PAUSE`、`RESUME`、`END`、`RESTART`、`MODE`、`EDIT`。`MODE` 指定 `value` 和 `seconds`，其他命令填 `0,0` |
| `@EDIT,seq,rev,row,col,piece` | 编辑指定格，仅编辑阶段有效 |

扩展成功帧 `@GAME,seq,rev,turn,status,black,white,cells,mode,phase,round,total,losses,remainingMs,elapsedMs,edited,result,limitSeconds`。

`@GAME3`、`@GAME4` 和 `@GAME5` 沿用上述字段，在末尾追加 `stage,scoreHalf,totalHalfPoint`。闯关的 `stage` 为 1–4，其他模式为 0。`scoreHalf` 每单位为半分。累计分为 `total + totalHalfPoint / 2`，其中 `totalHalfPoint` 为 0 或 1。

- `mode` 为本局存档模式，普通 `0`、闯关 `1`、计时 `2`、EN 对弈 `4`。模式 `3` 保留给旧固件的板载 AI 档案。旧协商格式读取新版 EN 局时按普通 `0` 显示棋盘。`phase` 为运行 `0`、暂停 `1`、编辑 `2`、结束 `3`。`@GAME4`、`@GAME5` 的闯关 `WIN`／`OVER` 保留 `mode=1` 和关卡分数，上位机同时标明已退出闯关。
- `result` 为进行中 `0`、自然终局 `1`、时间到 `2`、主动退出 `3`、`WIN` 为 `4`、`OVER` 为 `5`。
- `round` 标识当前设备会话内的局号。轮询计时可返回相同修订号、不同剩余时间，收包时无需重放动作。
- 错误帧保持 `@ERROR,seq,reason`。电脑回合提交人工落子返回 `COMPUTER_TURN`，在非 EN 回合提交 AI 指令返回 `NOT_AI_TURN`。主动同步为当前协商格式，序号为 0。新主机先探测 `@SYNC5`，遇到 `COMMAND` 依次回退到 `@SYNC4`、`@SYNC3`、`@SYNC2`、`@SYNC` 和 `@GET`。旧版 `@GET`／`@MOVE` 使用 `@STATE`。
