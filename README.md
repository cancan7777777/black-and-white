# 黑白棋单片机课程设计

2026 单片机课程设计第 14 题：黑白棋游戏。

**当前阶段：已启动基础功能审查和离线 STM32CubeMX 工程配置（#20）。硬件搭建、完整游戏固件、LabVIEW 上位机与 AI 尚未完成。**

## 项目目标

用 4×4 矩阵键盘和 8×8 RGB LED 点阵完成实体黑白棋，与上位机通过串口双向交互；覆盖任务书的基本要求、进阶要求和项目完整性要求，并保留可复核的验收记录。

参考路线为 STM32F103C8T6 + WS2812B + LabVIEW 9。Python / Egaroucid 是后续 AI 扩展，不替代课程规定功能。具体型号、环境和未明确的游戏规则需在实现前冻结。

## 范围与完成口径

- 必做：基本功能、进阶功能、稳定性与完整性；以逐项验收为完成依据。
- 扩展：AI 推荐、人机对弈、复盘分析；必做功能通过后再安排。
- 可选研究：胜率校准、AI 自适应难度、EViews 统计。
- 项目建项完成不等于实验系统完成。规划任务可关闭，所有实现任务保持未开始。
