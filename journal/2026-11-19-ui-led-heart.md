# LabVIEW 界面与点阵爱心动画

- 用户授权放大 LabVIEW 按钮、优化界面，在对局结束时用获胜方棋色逐个点亮 LED 组成爱心，并更新 GitHub。沿用 [#12](https://github.com/cancan7777777/black-and-white/issues/12) 和 [#5](https://github.com/cancan7777777/black-and-white/issues/5)。分支 `task/12-ui-led-heart` 基于四关规则提交 `6390001`。
- 界面以棋盘为主，分组显示串口、对局操作和关卡计分，保留本机 `Main.vi` 的现有改动。以真实上位机控件渲染预览，并复跑原有按钮和协议检查。
- 自然终局或计时结算按盘面棋子数确定当局获胜方。黑方橙色，白方青色。LED 从上往下逐个点亮，闯关有 WIN 或 OVER 时在动画后滚动文字。平局和主动退出跳过爱心。复核纯 C 显示规则、Keil 构建和 ATK-XISP 文件，实体观感待板上验证。

## 执行与验证

- 将串口参数和三项串口操作集中在连接栏。七个对局按钮单独成行。棋盘居中，黑棋橙边、白棋青边，右栏显示当前回合、关卡系数和累计分。放大回放步进与导出按钮。保留现有 VI 的程序集入口、按钮操作和数据协议。
- 点阵服务使用现有 PWM/DMA。结算开始后每 45 ms 增加一盏灯，40 灯完整点亮耗时 1755 ms。普通终局维持完整爱心，闯关最终 WIN 或 OVER 在保持 700 ms 后滚动文字。开始新局或切换模式会恢复棋盘显示。
- `tools/build-labview.ps1 -OutputDirectory build/labview/ui-heart/bin` 构建 x86 上位机。C 测试通过，覆盖胜方、平局、主动退出、计时、点亮次序和间隔。77 项上位机检查通过，其中包含最小尺寸的按钮热区、离线落子和人机应手。直接渲染实际 .NET 组件检查 1060×720 和 1000×660 布局。将三项编译产物复制到标准 `labview/Othello_Basic/bin` 目录并核对文件哈希。
- `tools/build-keil.ps1` 返回 0 错误、0 警告。输出复制到 `build/Othello_Challenge_Heart.hex`。1027 条 Intel HEX 记录的长度和校验和均通过，扩展地址为 `0x08000000`。SHA-256 为 `6FAE8510987A2C225536EFD996BF7B6ED623323B2CE7A57366FA8955E14E4BAE`。
- 实体烧录和点阵颜色、方向、动画观感仍待在板上验收。#5 与 #12 保持开放。
