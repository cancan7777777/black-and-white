# BOM 硬件国内价格调研与总价测算

- 用户要求：调研 `黑白棋课程设计总体方案.md` §3.1 硬件组成在国内的价格，并给出总价。对应 Issue [#36](https://github.com/cancan7777777/black-and-white/issues/36)，父任务 [#3](https://github.com/cancan7777777/black-and-white/issues/3)（T02 硬件核实）。
- 授权范围：只做价格检索、比价与文档留痕。不采购、不接线、不上电、不刷机、不安装依赖。
- 采集时间：2026-11-21（Asia/Shanghai）。所有价格均为当日页面标价快照，不是报价单，也不含运费。

## 背景

- 开工前翻过 `journal/`：`2026-11-17-project-planning.md`、`2026-11-18-basic-audit-cubemx.md`、`2026-11-20-proteus-guide.md` 都提到过硬件，但没有一条记录过价格或采购成本；本轮是首次做成本测算，无可沿用的旧结论。
- `docs/plan.md` §6 把「准确板卡/晶振、点阵型号及映射、独立供电、电平转换、实际键盘布局、下载方式」列为待定决策。本轮价格数据的作用是给这些待定项加一个「选哪种形态、花多少钱」的量化维度，不替代实物核实。
- 方案原稿 §3.1 的 8 行硬件就是本次比价清单；§3.3 的供电要求（WS2812B 独立供电、共地、亮度限制）决定了电源一档不能只按最便宜的 5V/1A 选。

## 方法与口径

1. 检索面：本机 `web_search` 无可用 API key（`DeepSeek search has no API key for "DEEPSEEK_API_KEY"`），浏览器工具也不可用（`the bsk CLI ("bsk") was not found`），因此全部走 HTTP 抓取。
2. 京东、淘宝、拼多多、天猫、苏宁、唯品会、慢慢买等 C 端商城的搜索页对无头抓取一律返回 JS 壳或跳转（`cross-origin redirect to https://cfe.m.jd.com`、`s.taobao.com` 只剩 `g_config` 脚本），**没有拿到任何 C 端零售价**。这一点如实记下，不用二手博客里的数字凑。
3. 实际取到数据的两类站点：
   - **1688 关键词聚合页** `https://www.1688.com/chanpin/-<GBK十六进制关键词>.html`：页面内嵌 schema.org `ItemList`，含 `name` / `url` / `offers.price`，可直接解析出 60 条/页的真实报价。这是本轮主力来源。**注意这是批发/起批价，不是零售单价。**
   - **华秋商城 hqchip.com**：搜索结果页 `class="price-cell"` 为自营含税阶梯价，商品页 `国内含税` 明确标价。作为「零售现货」一档的对照。
   - 补充：立创商城 `item.szlcsc.com/9243.html` 的 STM32F103C8T6 裸芯片 ￥5.7（C8734，LQFP-48）。
4. 口径约定：
   - 1688 价格 = 起批量单价，未含运费，多数档位需 2 件起或整包购买。
   - 华秋价格 = 国内含税自营价，1 件起订，不含运费。
   - 「典型」一档取中位常见成交价，不是最低价，也不是最高价。

关键辨析（这几条写进表里容易混，单独说明）：

1. **裸芯片 ≠ 最小系统板。** 立创 ￥5.7 是 LQFP-48 裸片 C8734，买回来不能直接插面包板；本方案要的是带晶振、稳压、排针、USB 的「蓝 pill / 核心板」，1688 ￥4.18–9.9，华秋自营 ￥10.44。表里取的是**板**的价格。
2. **柔性像素屏 ≠ 硬板模组。** ￥8.5–13 的绝大多数是 FPC 软板（背面带双面胶，排线引出），贴合亚克力/纸板即可；硬板 WS2812B-64（`offer/616796606232` ￥26）刚性更好但贵约 2.5 倍。方案 §3.1 写的是「已经集成好的 8×8 点阵模块」，两种都满足，需实物确认接口与像素排列。
3. **不要买 MAX7219 点阵。** 1688 上 ￥3–13 的「8×8 点阵模块」大量是 MAX7219 单色/红色模组，与 WS2812B 全彩方案完全不同，不能因为便宜就替换。搜索时必须以 `WS2812B` 为关键词。

## 总价

| 方案 | 组成 | 总价 |
|---|---|---:|
| A 最低可跑 | 全按 1688 起批最低价，5V/2A 电源 | **￥22.14** |
| B 典型 | 各件取常见成交价，5V/2A 电源 | **￥26.94** |
| C 典型 + 足额供电 | B 把 5V/2A 换成 5V/5A（￥7.70） | **￥32.14** |
| D 硬板模组方案 | C 把柔性屏换成硬板 WS2812B-64（￥26） | **￥48.54** |
| E 零售现货 | 全按华秋自营含税价取高值 | **￥48.99** |

按方案原稿「WS2812B 独立供电」的要求，**C 是推荐口径：约 ￥32**。理由是 64 颗 WS2812B 全白满亮约 3.84 A（60 mA/颗），5V/2A 适配器在满亮时会掉压甚至保护；即使按 §3.3 做亮度限制，5V/2A 也只剩不到一半余量。要留余量就得 5V/4–5A，多花约 ￥5。

## 未计入项

以下不在原稿 BOM 里，但真做下去大概率要买，如实列出而不擅自加进总价：

- 运费：1688 多为「满额包邮」，小批量单件通常 ￥8–12 起。
- 亚克力/纸板背板、铜柱、螺丝：做成品外观才需要。
- 万用表、烙铁、焊锡：若已有则不重复投入。
- ST-Link / DAP-Link 调试器：方案用 USB-UART 串口下载，但排错阶段通常还是需要一个 SWD 调试器（￥10–20 区间，本轮未逐一比价，标**待核实**）。
- 备用件：WS2812B 像素屏与薄膜键盘都属于易损件，建议各多备 1 件，约 +￥11。

## 结果

- 完成 §3.1 全部 8 行硬件的国内价格区间采集，每行至少一个可复核 URL。
- 三档总价：最低 ￥22.14 / 典型 ￥26.94 / 足额供电 ￥32.14；硬板与纯零售口径上探到 ￥48–49。
- 推荐按 **￥32（方案 C）** 做预算，并额外预留 ￥20 左右给运费、备用件与调试器。
- 已明确记录两条易错点：裸芯片与最小系统板差一倍以上；MAX7219 单色点阵不能当 WS2812B 全彩屏用。

## 遗留

- 京东/淘宝/拼多多的 C 端零售价未取到（反爬），当前「零售」一档只有华秋自营一个样本。若需要更贴近淘宝实付价，需在有浏览器会话的环境里人工核对。
- ST-Link/DAP-Link、亚克力面板、备用件未比价，标**待核实**。
- 具体选柔性屏还是硬板、选 5V/2A 还是 5V/5A，取决于 #3 的实物核实结果（像素排列、DIN 方向、接口形式），本轮只给价格不替用户决策。
- 价格有时效性，超过约一个月需重采。
